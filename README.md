# SARITA dashboard (static frontend)

Live site: https://rounak251.github.io/sarita-flood-dashboard/

Frontend of SARITA (SAR-based Inundation Tracking & Analytics): Sentinel-1 flood mapping for the 2024 Kosi floods in North Bihar, plus the Bandh-Rakshak embankment view (`#bandh`) and the patrol app (`patrol/`).

This copy runs as a static site with bundled data. Features that call the model (bulletins, chip prediction, uploads, inspection-order download) need the FastAPI backend, which is not hosted here.
